מבנה מחשבים — הוראות הפעלה למחשב (Windows / Mac)

מתחילים ללמוד תוך 20 שניות, 100% אופליין וללא התקנת תוכנות.

הפעלה מיידית במחשב (20 שניות)

1
חלץ את כל התיקייה: לחץ קליק ימני על קובץ ה־ZIP ← חלץ הכל / Extract All (ב־Mac פשוט דאבל־קליק). אל תפתח קבצים ישירות מתוך ה־ZIP בלי לחלץ, כדי שהקישורים בין הפרקים יעבדו.
2
פתח את שער הקורס: דאבל־קליק על 00_Course_Hub_HE.html (ייפתח ב־Chrome / Edge / Safari).
3
בחר פרק והתחל ללמוד: בצד ימין תראה את ההסברים והשקפים ובצד שמאל את הסימולטור החי — אפשר לגרור את המחיצה ביניהם, ולחזור בכל רגע ל־🏠 שער הקורס.

בונוס: רוצה ליצור קישור אחד שעובד בטלפון ובאייפד בלחיצה? (2 דקות)

התיקייה הזו כבר כוללת index.html, manifest.json ו־sw.js (מצב אפליקציה + שמירה אופליין):

  • היכנס במחשב לאתר החינמי app.netlify.com/drop (או GitHub Pages).
  • גרור את כל התיקייה המחולצת למסך — תוך 30 שניות תקבל קישור קבוע.
  • שלח את הקישור לעצמך או לחברים: בטלפון ובאייפד הוא נפתח מיד בדפדפן, ובכפתור "הוסף למסך הבית" הופך לאפליקציית קורס מלאה שעובדת גם בלי קליטה!
